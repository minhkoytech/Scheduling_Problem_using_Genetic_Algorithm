# Hospital Staff Scheduling Using Genetic Algorithm (GA)

This project applies a **Genetic Algorithm (GA)** to solve the hospital staff scheduling problem by automatically generating optimized work schedules based on predefined constraints.

## Installation

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Install the required Python libraries:

   ```bash
   pip install simpleai numpy kanren wxPython
   ```

3. Download the JSON dataset provided in this repository.

## Usage

1. Open **`Lichlamviec.ipynb`** using Jupyter Notebook.

2. Press **Ctrl + F** and search for **`.json`**.

3. Replace the JSON file path with the dataset you want to use. You can use different JSON files to test multiple scheduling scenarios.

4. Run all cells in **`Lichlamviec.ipynb`** to execute the Genetic Algorithm and generate the hospital staff schedule.

## Requirements

* Python 3.x
* Jupyter Notebook
* simpleai
* numpy
* kanren
* wxPython
