Hospital Staff Scheduling Using Genetic Algorithm (GA)

This project uses a Genetic Algorithm (GA) to generate an optimized work schedule for hospital staff.

Installation & Usage
Clone the repository
Clone or download the source code from GitHub.
Install the required libraries
Install the following Python packages:
simpleai
numpy
kanren
wxPython
Download the JSON dataset
Download the JSON file provided in the GitHub repository.
Configure the dataset
Open Lichlamviec.ipynb.
Press Ctrl + F and search for .json.
Replace the JSON file path with the dataset you want to use.
You can switch between different JSON files to test multiple scheduling scenarios.
Run the project
Open Lichlamviec.ipynb in Jupyter Notebook.
Run the notebook cells to debug, execute the algorithm, and generate the work schedule.
